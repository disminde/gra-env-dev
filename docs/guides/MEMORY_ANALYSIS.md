## 📊 一、迁移过程分阶段内存分析

### 阶段 1: Python 脚本启动和初始化
```
时间：0-10 秒
内存峰值：~50 MB
```

**内存消耗组成**：
- Python 解释器基础：~20 MB
- 导入的库（psycopg2, csv, logging）：~15 MB
- 配置对象和变量：~5 MB
- 日志缓冲区：~10 MB

**结论**: ✅ 内存占用极低，可忽略不计

---

### 阶段 2: 创建临时 CSV 文件（关键阶段）
```
预计耗时：15-25 分钟
内存占用：~30-80 MB（稳定）
```

**技术实现**：
```python
# 使用流式读取，每次只处理一行
for row in reader:
    new_row = row[1:]
    writer.writerow(new_row)
```

**内存分析**：
| 组件 | 内存占用 | 说明 |
|------|---------|------|
| CSV reader 缓冲区 | ~8 KB | 默认缓冲区大小 |
| CSV writer 缓冲区 | ~8 KB | 默认缓冲区大小 |
| 当前行数据 | ~1 KB | 单行数据内存 |
| Python 解释器 | ~20 MB | 基础运行内存 |
| 操作系统文件缓存 | ~50 MB | 由 OS 管理，不计入 Python |
| **总计** | **~30-80 MB** | 稳定状态 |

**关键优化**：
- ✅ 使用生成器逐行读取，**不一次性加载整个文件**
- ✅ 每行处理后立即释放，无累积
- ✅ 不使用 pandas 等重型库

**对比方案**：
```python
# ❌ 错误示范（会占用大量内存）
import pandas as pd
df = pd.read_csv('file.csv')  # 1.76 亿行会占用 ~20GB 内存！
```

**实现代码**：
```python
# 在训练脚本中添加内存监控
import psutil
import time

def check_memory():
    mem = psutil.virtual_memory()
    if mem.percent > 85:
        print(f"⚠️  内存使用率过高：{mem.percent}%")
        return False
    return True

# 训练循环中定期检查
for epoch in range(epochs):
    if not check_memory():
        print("暂停训练，等待内存释放...")
```

## 📋 六、监控工具推荐

### 1. Windows 任务管理器
```
打开方式：Ctrl + Shift + Esc
监控项：
- Python.exe 内存
- postgres.exe 内存
- GPU 显存使用
```

### 2. 命令行监控
```powershell
# 每 5 秒刷新一次内存使用
while($true) {
    Get-Process python,postgres | 
    Select-Object Name,WorkingSet,@{N='GB';E={$_.WorkingSet/1GB}} |
    Format-Table
    Start-Sleep -Seconds 5
}
```

### 3. Python 脚本监控
```python
# monitor.py
import psutil
import time

print("内存监控开始...")
while True:
    mem = psutil.virtual_memory()
    print(f"{time.strftime('%H:%M:%S')} - "
          f"总内存：{mem.total/1024/1024/1024:.1f} GB, "
          f"已用：{mem.used/1024/1024/1024:.1f} GB, "
          f"使用率：{mem.percent}%")
    time.sleep(10)
```
