## 1. 数据集介绍

### 1.1 推荐数据集

**中国地面气候资料日值数据集 (V3.0)**

**包含变量**：
- ✅ 气温：平均气温、最高气温、最低气温
- ✅ 降水：日降水量
- ✅ 相对湿度：平均相对湿度
- ✅ 风速：平均风速、最大风速
- ✅ 日照时数：用于推算太阳辐射 ⭐
- ✅ 蒸发量
- ✅ 本站气压

**时间范围**: 1951 年 1 月至今  
**空间覆盖**: 全国 2421 个气象站点（其中华北平原约 100+ 站点）  
**数据格式**: 按年 - 月存储的文本文件  
**更新频率**: 每月更新

### 1.2 为什么选择这个数据集？

1. **变量齐全** - 包含 Penman-Monteith 公式所需的全部 4 个变量
2. **时间长** - 70+ 年数据，满足机器学习训练需求
3. **站点密** - 华北平原站点间距约 30-50km
4. **质量好** - 经过严格质量控制
5. **免费** - 学术用途完全免费

## 2. 注册流程

### 2.1 准备工作

- **校园邮箱**（.edu.cn 后缀，审核更快）
- **学生证/工作证照片**（可能需要）
- **身份证明**（姓名、单位、研究方向）

### 2.2 注册步骤

**步骤 1**: 访问官网
```
网址：http://data.cma.cn/
```

**步骤 2**: 点击注册
- 右上角找到"注册"按钮
- 选择"个人用户注册"

**步骤 3**: 填写信息
```
必填项:
- 用户名（建议用真实姓名拼音）
- 密码
- 邮箱（必须用校园邮箱！）
- 真实姓名
- 身份证号
- 所在单位（填写学校全称）
- 职业（选择"科研人员"或"学生"）
- 研究方向（填写"气象干旱监测"或"气候变化"）
```

**步骤 4**: 邮箱验证
- 登录校园邮箱查收验证邮件
- 点击验证链接完成验证

**步骤 5**: 等待审核
- 审核时间：1-3 个工作日
- 审核结果通过邮件通知

## 4. API 接口使用

### 4.1 API 概述

**API 地址**: `http://api.data.cma.cn:8090/`

**支持的数据类型**:
- 地面气象资料（含日值、小时值）
- 高空气象资料
- 卫星遥感产品
- 雷达数据

### 4.2 获取 API 密钥

**步骤**:
1. 登录中国气象数据网
2. 进入"个人中心"
3. 找到"API 密钥管理"
4. 点击"申请 API 密钥"
5. 填写使用目的（学术研究）
6. 等待审核（1-2 天）

### 4.3 API 调用示例

**免费试用期**: 注册成功后 7 天免费使用

**调用格式**:
```http
GET http://api.data.cma.cn:8090/aio/cdc/surface/cli/day?
    dataCode=SURF_CLI_CHN_MUL_DAY-01
    &staIds=533520
    &time=199001
    &key=YOUR_API_KEY
```

**参数说明**:
- `dataCode`: 数据集代码
- `staIds`: 站点号（如 533520 北京站）
- `time`: 年月（YYYYMM 格式）
- `key`: API 密钥

**Python 调用示例**:
```python
import requests

API_KEY = "your_api_key"
BASE_URL = "http://api.data.cma.cn:8090/aio/cdc/surface/cli/day"

params = {
    'dataCode': 'SURF_CLI_CHN_MUL_DAY-01',
    'staIds': '533520',
    'time': '199001',
    'key': API_KEY
}

response = requests.get(BASE_URL, params=params)
data = response.json()

# 解析数据
if data['code'] == 200:
    print(data['data'])
else:
    print(f"Error: {data['message']}")
```

1. **调用频率限制**: 
   - 普通用户：100 次/天
   - 认证用户：1000 次/天

2. **数据量限制**:

   - 单次最多 10 年数据

3. **API 有效期**:
   - 免费试用 7 天

**方式 2**: API 下载


**方式 3**: FTP 下载（大数据量）
```
需要单独申请 FTP 账号
适合下载全部历史数据
```

### 5.2 数据格式说明

**文件命名规则**:
```
SURF_CLI_CHN_MUL_DAY-01-533520-202001.TXT
数据集代码 - 站点号 - 年月.TXT
```

**文件格式**（固定宽度文本）:
```
站号    年份  月份  日期  平均气温  最高气温  最低气温  降水量  ...
533520  2020  01    01    -5.2     2.1      -10.5    0.0     ...
```

**数据说明**:
- 温度单位：°C（×10 存储，需要除以 10）
- 降水单位：mm（×10 存储）
- 风速单位：m/s（×10 存储）
- 日照单位：h（×10 存储）
- 缺测值：999999

### 5.3 Python 处理示例

```python
import pandas as pd
import glob
from pathlib import Path

def parse_cma_data(file_path):
    """
    解析中国气象数据网数据
    """
    # 读取固定宽度文件
    df = pd.read_fwf(
        file_path,
        widths=[8, 5, 3, 3, 6, 6, 6, 6, 6],  # 根据实际格式调整
        names=['station', 'year', 'month', 'day', 
               'temp_avg', 'temp_max', 'temp_min', 
               'precip', 'sunshine'],
        skiprows=1
    )
    
    # 处理缺测值
    df = df.replace(999999, None)
    
    # 转换单位（×10 的数据）
    temp_cols = ['temp_avg', 'temp_max', 'temp_min']
    for col in temp_cols:
        df[col] = df[col] / 10.0
    
    df['precip'] = df['precip'] / 10.0
    df['sunshine'] = df['sunshine'] / 10.0
    
    # 创建日期列
    df['date'] = pd.to_datetime(df[['year', 'month', 'day']])
    
    return df

# 批量处理
data_dir = Path('data/raw/china_met_data')
all_files = glob.glob(str(data_dir / '*.TXT'))

df_all = []
for file in all_files:
    df = parse_cma_data(file)
    df_all.append(df)

df_final = pd.concat(df_all, ignore_index=True)
print(f"总共 {len(df_final)} 条记录")
```

## 6. 常见问题

### Q1: 校园邮箱收不到验证邮件？

**解决方法**:
1. 检查垃圾邮件箱
2. 添加 data.cma.cn 到白名单
3. 尝试其他校园邮箱（如从 163 改到学校官方邮箱）
4. 联系数据网客服：data@cma.cn

### Q2: 审核被拒绝怎么办？

**常见原因**:
- 申请理由不充分
- 身份信息不清晰
- 数据用途不明确

**解决方法**:
- 重新填写申请理由（参考模板）
- 附上学生证和导师信息
- 强调学术研究用途

### Q3: 需要华北平原 100 个站点，如何选择？

**推荐方案**:
```
方案 1: 下载全部 2421 个站点，然后筛选
方案 2: 申请时指定省份（北京、天津、河北、山东、河南）
方案 3: 使用站点列表文件筛选（经纬度范围）
```

**华北平原范围**:
```
纬度：32°N - 42°N
经度：112°E - 122°E
```

### Q4: API 调用失败，错误代码 401？

**原因**: 未授权（API 密钥错误或过期）

**解决**:
1. 检查 API 密钥是否正确
2. 确认 API 权限是否在有效期内
3. 重新申请 API 密钥

### Q5: 数据缺测严重怎么办？

**处理策略**:
1. 缺测<5%：直接删除
2. 缺测 5-20%：插值填补（线性插值、邻近站插值）
3. 缺测>20%：考虑更换站点或使用再分析数据

### Q6: 如何引用数据？

**推荐引用格式**:
```
数据来源：中国气象数据网 (http://data.cma.cn)
数据集：中国地面气候资料日值数据集 (V3.0)
引用时间：2026 年 3 月
```
